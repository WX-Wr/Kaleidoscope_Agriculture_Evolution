# 森罗物语：农业进化 —— 基因系统玩法教程

## 一、概述

基因系统是本模组的核心玩法之一。每种作物都拥有一套完整的基因组，基因决定了作物的**生长速度**和**产量**。通过选择性育种、杂交授粉和世代选育，玩家可以培育出远超野生品种的优良作物。

目前支持基因系统的作物：**小麦、胡萝卜、马铃薯、甜菜根**。

---

## 二、核心概念

### 2.1 染色体与基因座

每种作物的基因组由 **2 条染色体** 组成，每条染色体上分布着若干**基因座**（Gene Locus）。所有基因均为**数量性状基因**（Quantitative），每个基因座的等位基因值范围为 **0~4**（5 个等级），值越大代表性状越优良。

| 染色体 | 名称 | 包含基因座 |
|--------|------|-----------|
| 0 号 | 生长 | 生长速度 |
| 1 号 | 产量 | 产量、果实大小、结实率 |

### 2.2 等位基因与基因型

每个基因座存储**两个等位基因**（分别来自父本和母本的同源染色体），显示格式为 `[A/B]`：

- `[2/2]`（白色）—— **纯合子**，两个等位基因相同
- `[2/4]`（青色）—— **杂合子**，两个等位基因不同

### 2.3 表现型

基因型经过评估后产生**表现型**（Phenotype），即实际影响游戏玩法的数值：

- **生长速度倍率** — 影响作物在每个 randomTick 中的生长概率，以及可能触发的额外生长阶段
- **产量倍率** — 影响收获时掉落的种子数量
- **结实率倍率** — 直接影响种子掉落数量：`种子数 = max(1, round(1 + seedMult))`

### 2.4 等级评定

表现型数值会被转换为直观的字母等级：

| 等级 | 相对值范围 | 颜色 | 含义 |
|------|-----------|------|------|
| S | ≥ 90% | 金色 | 极品 |
| A | ≥ 70% | 绿色 | 优秀 |
| B | ≥ 55% | 黄色 | 良好 |
| C | ≥ 40% | 灰色 | 一般 |
| D | < 40% | 深灰 | 较差 |

## 三、野生品种

自然生成或初始种植的作物均为**野生品种**。野生品种的等位基因按照以下概率分布随机生成：

| 等位基因值 | 出现概率 |
|-----------|---------|
| 0 | 30% |
| 1 | 30% |
| 2 | 22% |
| 3 | 13% |
| 4 | 5% |

可以看到，高价值等位基因（3、4）在野生种群中非常罕见。要通过育种才能富集优良基因。

---

## 四、基因育种机制

### 4.1 减数分裂与配子形成

当作物繁殖时，亲本通过**减数分裂**产生配子（花粉/卵细胞）：

1. 每条染色体随机选择从父源或母源同源染色体开始
2. 沿染色体扫描每个基因座，根据**遗传连锁距离**（使用 Haldane 作图函数计算）决定是否发生**交叉互换**
3. 交叉互换后，切换正在使用的同源染色体
4. 每个等位基因有概率发生**突变**

**关键影响**：同一条染色体上的基因座距离越近，越容易被一起遗传（连锁遗传）。例如，产量染色体上的"产量"（位置 0）、"果实大小"（位置 22）、"结实率"（位置 40）之间存在连锁关系——"产量"和"果实大小"之间的交叉互换概率高于"果实大小"和"结实率"之间。

### 4.2 杂交（Crossing）

两个不同亲本杂交时，各产生一个配子，合并形成子代基因型。子代会混合父母双方的遗传特征。

### 4.3 自交（Self-Pollination）

如果只有单亲（没有外来花粉），作物进行自交——从同一亲本产生两个配子合并。自交会导致杂合度逐代降低，优良性状逐渐纯合固定。

### 4.4 突变

每个等位基因在配子形成时有独立的突变概率：

- 基础突变率：每个基因座 **0.005**（0.5%）
- 可被配置项 `mutation_rate` 倍率调整
- 数量性状突变：70% 概率 +1，30% 概率 -1（值在 0~4 范围内限制）

突变是获得高价值等位基因（如 4 等位基因）的重要途径。

### 4.5 杂种优势（Heterosis/Hybrid Vigor）

杂合子拥有额外的**杂种优势加成**：

- **产量杂种优势**：`1.0 + 0.15 × 产量相关基因座杂合度`
- **生长杂种优势**：`1.0 + 0.10 × 生长相关基因座杂合度`

这意味着 F1 杂交种（高度杂合）通常比纯合亲本表现更好。但连续自交会导致杂合度下降、杂种优势衰退——这就是经典的"F2 衰退"现象。

## 五、授粉机制

### 5.1 自动授粉

作物生长至成熟阶段时，有概率发生授粉：

- 基础概率由 `pollination_chance` 配置控制（默认 **5%** 每 randomTick）
- 首先检查自交偏向（`selfPollinationBias`），不同作物不同：
  - 小麦：**70%** 自交（闭花授粉，自交率高）
  - 胡萝卜：**30%** 自交（异花授粉，杂交率高）
  - 马铃薯：**50%** 自交
  - 甜菜根：**65%** 自交
- 若不自交，检查周围 8 格（四方向 + 四对角）是否有同种成熟作物
- 找到后，将邻近作物的基因组设为花粉来源

### 5.2 人工授粉

玩家可以手持**同种作物的种子**右键点击已种植的作物来进行人工授粉：

- 手持种子的基因组将成为目标作物的花粉来源
- 即使种子没有遗传数据（野生种子），也可以作为花粉使用
- 成功后会显示"已授粉！"的提示消息

### 5.3 授粉效果

被授粉的作物在收获时，子代基因型 = 母本植株基因 × 花粉基因，产生全新的子代种子。

## 六、基因分析器

### 6.1 制作与使用

**基因分析器**（Gene Analyzer）是本模组的核心工具物品，不可堆叠。

手持基因分析器**右键**任何已种植的作物，会在聊天栏显示详细的遗传分析报告：

```
========== 小麦 ==========
  生长: A
  产量: B
基因型：
 生长: 生长速度[3/3]
 产量: 产量[2/4]  果实大小[4/4]  结实率[1/1]
（已有外来花粉）
```

- 等位基因值 `[2/4]` 为**青色**表示杂合子，`[3/3]` 为**白色**表示纯合子
- 高产量品种（A/S 级）会显示特殊的金色标题
- 如果作物已被授粉，底部会显示紫色提示

### 6.2 种子提示

将种子放在物品栏中悬停，也会显示简略的遗传信息：

- 无遗传数据：显示灰色斜体"野生品种"
- 有遗传数据：显示"=== 遗传性状 ==="标题，以及生长和产量等级
- 按 F3+H 开启高级提示框后，额外显示完整的基因型字符串

---

## 七、高产品种的视觉表现

当作物产量等级达到 **A 或 S** 时，成熟作物会显示特殊的视觉效果：

- 小麦：切换为**高杆小麦模型**（约两倍高度的金色麦穗）
- 胡萝卜 / 马铃薯 / 甜菜根：替换为高产变体纹理
- 所有高产作物：成熟时获得**金色色调**着色（#F5D442）

---

## 八、生长速度详解

基因决定的生长速度影响作物的实际生长过程：

| 生长倍率 | 效果 |
|---------|------|
| < 0.01 | 作物完全停止生长 |
| < 1.0 | 每次 randomTick 仅有 `倍率 × 50%` 的概率生长 |
| = 1.0 | 正常生长 |
| > 1.0 | 一次 tick 可能触发多次生长（如 2.5x → 1 次必然 + 50% 概率额外 2 次） |

环境因素也会影响实际生长速度：

- **土壤湿润度**：干燥农田（moisture=0）降至 25% 速度，完全湿润（moisture=7）为 100%
- **天空光照**：低于 9 级时速度减半

## 九、配置文件

在存档的 `serverconfig/` 目录下可调整遗传系统参数：

| 配置项 | 默认值 | 范围 | 说明 |
|--------|--------|------|------|
| `mutation_rate` | 1.0 | 0.0 ~ 10.0 | 全局突变率倍率 |
| `pollination_chance` | 0.05 | 0.0 ~ 1.0 | 每 randomTick 杂交授粉概率 |
| `visual_tint` | true | true/false | 是否启用基因视觉着色效果 |

## 十、进阶育种攻略

### 10.1 起步：获取基因分析器

首先制作基因分析器，用它扫描你种植的作物，了解它们的遗传信息。

### 10.2 选育优良品种

1. 大量种植目标作物（建议 20+ 株）
2. 用基因分析器逐株扫描，找出等位基因值较高的个体（重点关注产量基因座）
3. 筛选出 B 级以上的植株作为育种亲本

### 10.3 利用杂种优势

1. 选择两株不同来源的优良植株（基因型差异越大越好）
2. 用其中一株的种子对另一株进行人工授粉
3. 收获后获得 F1 杂交种子，通常拥有显著的杂种优势（产量 A/S 级）
4. F1 杂交种可直接大规模种植用于生产

### 10.4 固定优良性状

如果想稳定获得高品质种子：

1. 从 F1 群体中选择表现最好的植株
2. 连续自交 3~5 代（每代选择最优个体作为下一代的亲本）
3. 杂合度逐渐降低，优良等位基因变为纯合
4. 最终获得性状稳定、基因纯合的优良品种

> **提示**：纯合稳定的品种后代性状一致，适合批量种植；杂合品种单代表现最好但后代会出现性状分离。

### 10.5 跨物种注意事项

- **胡萝卜**自交率低（30%），天然杂交率高，适合利用邻居作物进行自然杂交育种
- **小麦**自交率高（70%），更需要人工授粉来实现杂交
- **甜菜根**成熟快（maxAge=3），育种周期最短，适合快速迭代
- 不同物种之间**不能**杂交

### 10.6 突变育种

如果长期无法获得高等位基因（如等位基因 4），可以提高 `mutation_rate` 配置来加速突变。不建议设置过高（>5.0），否则基因可能会不稳定。

## 十一、常见问题

**Q：为什么我的高产作物看起来和普通的一样？**
A：确保 `visual_tint` 配置项为 true，且作物已成熟（达到最大生长阶段）。只有产量等级 A/S 的成熟作物才会有视觉特效。

**Q：种子提示显示"野生品种"是什么意思？**
A：表示这个种子没有存储遗传数据。当它被种植时，会自动生成一套随机的野生基因组。

**Q：杂交后代为什么比亲本还差？**
A：如果亲本本身是 F1 杂交种（高度杂合），其 F2 后代会发生性状分离，出现退步。这是正常的孟德尔遗传规律。建议连续选育多代来稳定优良性状。

**Q：如何获得 S 级作物？**
A：需要产量相关三个基因座（产量、果实大小、结实率）的等位基因值都很高（接近 4/4），并且保持一定杂合度获得杂种优势加成。通常需要多代选育或利用突变。
